💕 Reconciliation Mode

When a disagreement happens, either partner can send a "Challenge Card."

Examples:

Do 10 pushups 💪

Send a voice note saying 3 things you appreciate about me 🎙️

Share a funny selfie 😆

Drink a glass of water 🚰

Tell me your favorite memory of us ❤️

Write a 50-word apology 📝

Send a random compliment 🌹




🔒 Soft Chat Lock

Instead of completely blocking chat:

Messages are limited to:

"I'm doing the challenge."

Voice notes.

Reaction emojis.

"Challenge completed."

This prevents the feature from becoming a punishment tool while still encouraging resolution.




✅ Completion Flow

Partner sends challenge.

Recipient accepts.

Challenge timer starts.

Recipient uploads proof (optional):

Photo

Video

Voice note

Presses "Completed".

Sender receives:

Accept Completion

Request Retry

Chat unlocks fully.
